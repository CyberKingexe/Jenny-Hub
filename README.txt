Jenny Hub PWA
==============
Included:
- index.html
- manifest.webmanifest
- service-worker.js
- robots.txt

The icons folder is intentionally NOT included because you already have it.
Place your existing icons/ folder beside these files.

Required structure:
/
├── index.html
├── manifest.webmanifest
├── service-worker.js
├── robots.txt
└── icons/
    ├── icon-32.png
    ├── icon-180.png
    ├── icon-192.png
    ├── icon-512.png
    └── icon-1040.png
